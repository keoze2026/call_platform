# CH-594 - AI audit accuracy: agent echo, Claude final label with the team's corrections (BACKEND + Server B host)

Sir, 5 Nov: "No voice AI is not working correctly - not priority but I need
100% accuracy before Monday." The Claude API key is bought (5 Nov).

Kept in its own file, not CHANGES.md: this patch is applied after the local
CH-580 / CH-581 commits, which also add to the end of CHANGES.md - two patches
adding to the same last line stop `git am`. Copy this entry into CHANGES.md
once everything is pushed.

## What was wrong

1. **The agent's echo counted as the caller.** The caller's line carries the
   agent's own voice back (line or speakerphone echo), a moment later and
   quieter. Silero heard speech there, so an agent-only call read "caller
   speaks" -> **Valid**. Checked with the real Silero model (v5.1.2) on real
   speech: agent-only calls with echo at -10 to -20 dB showed about 15.7 s of
   "caller speech" - all of it the agent.
2. **The LLM never decided anything.** CH-555's final label (transcript +
   Claude) stopped on "credit balance too low", so every label came from the
   rules alone. It also ran Claude at the default temperature: the same call
   could get two different answers.
3. **The team's Correct / Wrong verdicts were not used** ("use corrections to
   retrain").
4. **The Telegram No Voice alert went out on the rule label**, before the LLM
   - and stayed when the LLM then found the caller spoke.
5. **Cost:** every answered call, up to 300 s of both sides, would have been
   transcribed - including long, plainly real conversations.

## What changed

- `scripts/voice_check/voice_check.py` - `echo_free()`: a caller window is
  echo when the agent spoke in the 0.5 s before it (ECHO_LAG) and the caller
  side is under 35% of the agent's loudness then (ECHO_RATIO, about -9 dB).
  Echo is taken out of the caller's speech seconds and first-speech time;
  sent on as `caller_echo` and `caller_speech_raw`. The log line shows it:
  `caller speech 0.0s (+15.7s agent echo removed), agent speech 16.2s`.
  Real speech check (Silero v5.1.2):

  | call | caller before | caller after |
  |---|---|---|
  | agent only, echo 100-300 ms, -10 to -20 dB | 15.6-15.7 s | **0.0 s** |
  | real caller answering after the agent | 14.2 s | 8.9 s |
  | real caller talking over the agent, as loud | 14.7 s | 4.3 s (still Valid) |
  | quiet caller (-10 dB), agent silent | 14.4 s | 14.4 s |

- `routing/ai_labels.py`: the comment names the echo taken out
  ("agent echo on caller line 4.2 s (not counted)"); `needs_final()` - who
  goes to the LLM.
- `scripts/ai_final/ai_final.py`:
  - the instructions use Sir's own definitions (opening by the agent, "no
    human talking about their issue"), say how to spot echo in the
    transcript, that "hello?" alone is not a valid call, and to give LOW
    confidence when unsure;
  - ~~temperature 0~~ - removed in CH-600: Claude 5.5 refuses `temperature`
    ("deprecated for this model") and every call failed;
  - **the audit team's verdicts as worked examples** every run
    (`manage.py ai_final_examples`: the latest Wrong ones first - what the AI
    said, the right label, the team's note, the transcript - then some
    Correct ones). AI_FINAL_EXAMPLES (12; 0 = none);
  - AI_FINAL_MAX_SECONDS 300 -> **120** (the first two minutes decide it);
  - `--redo`: give the calls of the last `--days` their final label again,
    each once, with its own lock (never holds up the every-minute run).
- **Cost gate** (`ai_final_pending`, `AI_FINAL_SKIP_CALLER_SECONDS`, 15): a
  call the rules call Valid with 15 s or more of the caller's own speech is a
  real conversation and is not transcribed. 0 = every answered call.
- **The alert waits for the final label** (`AI_FINAL_ENABLED`, default
  False): with it on, `voice_results` holds the No Voice alert for calls the
  LLM will see; `ai_final_results` sends it once the LLM agrees (with its
  one-line summary, "AI: ..."), sends nothing if the LLM finds a real caller,
  and sends it on the rule label if the LLM fails. A `--redo` never sends one
  twice. Calls the LLM never sees (not answered, no recording, audio fault)
  alert at once as before.

| ANTHROPIC_API_KEY, ASSEMBLYAI_API_KEY | - | host script (ai_final.py) |

containers are created: `docker compose up -d ...` (not `restart`) after
calling hours.
